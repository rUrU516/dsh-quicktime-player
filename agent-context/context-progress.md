# Progress — what ships, what was verified

Last updated: 2026-11-05, version 0.1.2.

## Shipped

```
index.js            Host half: /quicktime/source, /quicktime/stream (Range), /quicktime/icon,
                    /quicktime/diag, /quicktime/_graph, plus a tokenized 127.0.0.1 media server
client.js           Browser half: own tab type + pane body + the player component (single file, no build)
icon.svg            Generated by scripts/make-icon.mjs (QuickTime silhouette, our colourway)
cordis.patch.yml    Bundle patch: inserts the `quicktime-player` row
test/               smoke (render) and browser (real Chromium via CDP) harnesses
```

## Verified

- **Tab takeover works in the live app.** Opened a 300 s video from a real session; the pane logged `tab-mount`
  with that address and `meta duration:300 w:1000 h:890 seekable:[0,300] transport:loopback`.
- **With and without another sidebar plugin installed**, videos route to this tab: that plugin's file tree hands the
  address over on its own (it probes the registry, sees our longer video glob win, and defers).
- **Range works**: `200` + `accept-ranges`, `206` + `content-range` for `bytes=a-b`, suffix ranges, `416` for
  unsatisfiable.
- **Player works in a real Chromium** (`node test/browser.cjs`): `readyState 4`, `duration 20`, `seekable [0,20]`,
  wheel zoom `1× → 1.54×`, rate slider → `playbackRate 2.4`, the clock toggles to `#0 / #600`, `ArrowRight` steps
  0.0333 s and pauses, and `Space` still reaches the player while a slider is focused.
- **Icons**: `GET /quicktime/icon` serves the SVG; the plugin list reads `package.json.icon`.
- **Published**: `npm pack` contents match the working tree byte for byte; installing from the registry into a fresh
  profile works and the bundle entry is added automatically.

## Seams and gotchas

- The `documentPreviews` registration is kept as a fallback for callers that name the native `text` kind explicitly.
  It is no longer the primary path.
- Frame numbers are estimated from `requestVideoFrameCallback`; before the first playback the rate defaults to 30.
- `.mkv` / `.avi` / `.wmv` / `.flv` are claimed but Chromium cannot decode them; the player shows a readable error.
- `~/.dsh/quicktime-player.log` is the client-side diagnostic channel (`tab-mount | meta | error | failed`).
- Hot reload: editing `client.js` is picked up by client-hmr within seconds. Editing `index.js` needs a profile
  recompose — touching the profile's `cordis.patch.yml` triggers one; no restart required.
